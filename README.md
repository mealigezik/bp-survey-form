# Bilge Panter Survey Form Demo

A responsive HTML/CSS survey mock-up for demonstration and learning.

## Privacy and data handling
This is a local-only demo. Submitting the form previews entered values in the current page session; it does not upload or store them. Do not enter real contact, health, or other personal data.

Before adapting this for production, use a secure backend and define data minimization, retention, access controls, and a privacy notice. Do not send personal data in URL query parameters.

## Run
Open `index.html` in a browser.

Automated tests have not been added.
